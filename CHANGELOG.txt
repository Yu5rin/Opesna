Opesna Changelog
================

v1.0.1 (2026-07-19)
  記録・キャプチャ精度
  - クリック種別（シングル/ダブル/右クリック）の判定をタイマー方式に刷新
  - クリックした要素名をステップタイトルに反映
  - Win32 WindowFromPoint によるウィンドウ検出（非UIAアプリ対応）
  - クリック要素を最小範囲まで絞り込んで囲む
  データ保全
  - 注釈編集・新規作成・ファイルを開く・ウィンドウを閉じる際の未保存確認を追加
  - Delete キーによる誤削除・二重削除を修正
  エクスポート
  - 複数ステップのPDFエクスポート失敗を修正、余白設定を修正
  - 既定ファイル名を統一、拡張子の二重付与を修正、PNGの選択枠写り込みを修正
  品質・UI/UX
  - 多重起動防止、エラーダイアログの日本語化とログ記録
  - 二重タイトルバーの解消、モーダルのフォーカス管理、各種ボタンの無効状態同期
  - 描画プレビューの消失を修正、Undo/Redo の一貫性改善
  配布
  - GitHub Actions リリースワークフロー追加
  - EXE名を Opesna.exe に、ビルドサイズを削減

v1.0.0 (2026-05-16)
  - 初回リリース
  - スクリーンショットキャプチャ（全画面・ウィンドウ・ファイルインポート）
  - 注釈ツール（矢印・四角・楕円・吹き出し・テキスト・ハイライト・モザイク・番号バッジ）
  - ステップ管理（追加・削除・並び替え）
  - テンプレート選択（6種類）
  - エクスポート（PDF・HTML・Markdown・PNG）
  - ショートカットキーカスタマイズ
  - 環境設定
  - .opn形式でのローカル保存
