Opesna Changelog
================

v1.1.0 (2026-09-25)
  追加
  - 自動更新: 起動時に新しい版を確認し、画面上部で知らせる。「更新する」を押したときだけ入れ替える（環境設定の「バージョン情報」から確認・オフにできる）
  - 保存していないプロジェクトを自動で退避し、次の起動で復元できるようにした
  - ホーム画面とメニューから記録を始められるようにした。記録は Ctrl+Shift+F9 でも停止できる
  - エクスポート: 用紙サイズ・向き・ページ番号を反映。Markdown は画像も書き出す。PNG は「現在のステップ／すべてのステップ」を選べる
  - エクスポート: 設定をプロジェクトごとに覚える。「前回と同じ設定でエクスポート」（Ctrl+Shift+E）と、完了後の「フォルダを開く」を追加
  - ホーム画面でプロジェクトの名前変更・フォルダへの移動・削除、フォルダの名前変更・削除ができるようにした
  - 文字の注釈を後から編集できるようにした。キャンバスに「画面に合わせる」表示を追加
  - ショートカットを環境設定の「ショートカット」タブで変更できるようにした
  修正
  - 上書き保存に失敗しても「保存しました」と表示され、変更を失うことがあったのを直した
  - フォルダを作れなかったのを直した
  - 画像が横につぶれて表示されていたのを直した
  - 記録のインジケーターを閉じると記録が止まらなかったのを直した。クリックの順序の入れ替わりも直した
  - 全画面キャプチャに Opesna 自身が写り込んでいたのを直した
  - 「名前を付けて保存」（Ctrl+Shift+S）が効かなかったのを直した
  - PDF の用紙サイズ・向き・ページ番号が効いていなかったのを直した
  - テンプレートによって文字が読めなかった配色を直した
  - 環境設定のスイッチが見えず、オン／オフが分からなかったのを直した
  - 細工されたプロジェクトファイルを開くとスクリプトが動く問題を直した
  変更
  - キャプチャのショートカットの既定を F9 にした（以前の既定の Ctrl+Shift+S のままなら自動で移す）
  - キャプチャした画像は、今のステップに画像が無ければそこへ、あれば直後に新しいステップを作って入れる。空のステップは作らない
  - モザイクは画像に直接書き込むようにした（元に戻すで取り消せる）
  - 番号バッジの番号をステップごとに振るようにした
  - 記録を始める前に、画面が撮影されることを案内するようにした
  - exe のフォルダに書き込めないときは、データを %APPDATA%\Opesna に保存する
  - 効かなかった設定（テーマ・言語・カーソルを含める・キャプチャ後に自動でステップ追加）を外した

v1.0.2 (2026-09-25)
  v1.0.1 はリリースを作る処理が失敗して配布できなかったため、その変更もこの版に含む
  修正
  - 「やり直し」ボタンの説明に出るショートカットを、実際に効くキー（Ctrl+Shift+Z）に合わせた
  - 拡大・縮小のショートカット（Ctrl+= / Ctrl+-）が効いていなかったのを直した
  変更
  - 環境設定の「自動バックアップ」を外した（切り替えても何も起きていなかったため）
  配布
  - リリースを作る処理が失敗していた（依存関係の記録の漏れ）のを直した

v1.0.1 (2026-07-19)
  記録・キャプチャ精度
  - クリック種別（シングル/ダブル/右クリック）の判定をタイマー方式に刷新
  - クリックした要素名をステップタイトルに反映
  - Win32 WindowFromPoint によるウィンドウ検出（非UIAアプリ対応）
  - クリック要素を最小範囲まで絞り込んで囲む
  データ保全
  - 注釈編集・新規作成・ファイルを開く・ウィンドウを閉じる際の未保存確認を追加
  - Delete キーによる誤削除・二重削除を修正
  エクスポート
  - 複数ステップのPDFエクスポート失敗を修正、余白設定を修正
  - 既定ファイル名を統一、拡張子の二重付与を修正、PNGの選択枠写り込みを修正
  品質・UI/UX
  - 多重起動防止、エラーダイアログの日本語化とログ記録
  - 二重タイトルバーの解消、モーダルのフォーカス管理、各種ボタンの無効状態同期
  - 描画プレビューの消失を修正、Undo/Redo の一貫性改善
  配布
  - GitHub Actions リリースワークフロー追加
  - EXE名を Opesna.exe に、ビルドサイズを削減

v1.0.0 (2026-05-16)
  - 初回リリース
  - スクリーンショットキャプチャ（全画面・ウィンドウ・ファイルインポート）
  - 注釈ツール（矢印・四角・楕円・吹き出し・テキスト・ハイライト・モザイク・番号バッジ）
  - ステップ管理（追加・削除・並び替え）
  - テンプレート選択（6種類）
  - エクスポート（PDF・HTML・Markdown・PNG）
  - ショートカットキーカスタマイズ
  - 環境設定
  - .opn形式でのローカル保存
