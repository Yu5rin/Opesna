Opesna v1.0 — 個人向け操作説明資料作成アプリ
==============================================

【起動方法】
  Windows: Opesna.exe をダブルクリック
  macOS:   Opesna をダブルクリック（初回は右クリック→開く）

【開発環境での起動】
  npm install
  npm start

【ファイル構成】
  app/         アプリ本体（変更しないこと）
  data/        プロジェクトファイルと出力先
  config/      設定ファイル（JSONで直接編集も可）
  templates/   テンプレート定義

【バックアップ】
  data/ と config/ フォルダをコピーすれば全データを保全できます。

【サポート】
  https://github.com/yu5rin/opesna
